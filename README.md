# ✦ FEATURE WALL

### 🎨 Experimental Visual System

The site avoids the typical corporate portfolio aesthetic and uses:

-   dark UI
-   colorful accent system
-   soft gradients
-   animated glow blobs
-   noise texture
-   bold typography
-   minimal cards
-   responsive layouts
-   micro-interactions

### 🌀 Animated Background

The hero uses floating blurred color blobs that slowly drift around the
page using CSS animations.

### ✦ Scroll Reveal

Project cards, stack items, vault cards and other components reveal
themselves as they enter the viewport using `IntersectionObserver`.

### 🥚 Easter Egg

There is a tiny egg hidden in the bottom corner.

**Click it.**

# 🎯 DESIGN PRINCIPLES

### 01 --- Personality \> Templates

Don't make it look like every other developer portfolio.

### 02 --- Show, Don't Claim

Instead of saying *"I'm interested in AI"*, show the experiments.

### 03 --- Keep It Fast

A visually interesting website doesn't need to be bloated.

### 04 --- Small Details Matter

Spacing, typography, transitions, hover states and micro-interactions
create quality.

### 05 --- Keep Evolving

The portfolio is designed to grow as new projects, skills and
experiments appear.
